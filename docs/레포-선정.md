# 수집 레포 30개 선정 근거

2026-09-10 확인한 기존 100개 후보에서 **10개 분야 × 3개, 총 30개**로 축소했다.
[기본 목록](../repos.txt)은 중복이 없으며, 분야는 주된 사용 목적 기준으로 분류했다.

## 축소 기준

- 사용자 요청에 따라 `NousResearch/hermes-agent`를 제외했다. 기존 확인 시 열린 이슈가 13,813개였다.
- 분야별로 GitHub Trending에서 관찰된 레포를 우선하고, 처리량을 줄이기 위해 열린 이슈가 상대적으로 적은 후보를 선택했다. `openai/codex` 등 이슈가 매우 많은 후보도 제외했다.
- **25개**는 기존 조회한 전체·언어별 월간 또는 전체 주간 Trending에서 확인됐다. 프런트엔드 2개와 백엔드 3개는 분야 균형을 위한 보완 선정이다.
- **24개**는 2023년 이후 생성됐다. 생성일은 프로젝트 최초 출시일과 다를 수 있다.
- 선정 당시 30개 모두 아카이브 상태가 아니고, 이슈 기능이 켜져 있으며, 최근 30일 내 push와 열린 이슈가 있었다. 열린 이슈는 레포당 최대 **362개**였다.

열린 이슈 수는 PR을 제외한 GitHub GraphQL `issues(states: OPEN).totalCount`이며 실제 수집량이나 소요 시간과 같지는 않다.
수집은 선택한 기간 내 갱신된 이슈를 읽으며, 담당자·봇 제외 후 모델 판정을 진행한다.
레포별 이슈 수는 다르므로 10개 분야의 수집 건수까지 균등하지는 않다.

수동 선정 스냅샷으로 자동 갱신하지 않는다. 아래 수치와 날짜는 기존 2026-09-10 API 조회 결과를 재사용했으며 날짜는 UTC 기준이다.
Trending 링크 내용은 이후 달라질 수 있다. 메타데이터는 인증된 `gh api graphql`로 조회했다.
원본 필드: `nameWithOwner`, `createdAt`, `pushedAt`, `isArchived`, `hasIssuesEnabled`, `issues(states: OPEN) { totalCount }`.
API 근거: [GitHub Repository 객체](https://docs.github.com/en/graphql/reference/objects#repository).

이 30개는 기존 100개 API 접근 점검에서 모두 `gh api repos/{repo}/issues?state=open&per_page=1` 조회에 성공했다.
이번 목록 변경은 새 30개 전체 이슈의 수집·판정 실측 결과가 아니다.
