# 수집 레포 100개 선정 근거

2026-09-10 확인. [기본 목록](../repos.txt)은 10개 분야에서 10개씩, 중복 없이 100개다.
분야는 주된 사용 목적 기준의 편집상 분류이며 프로젝트 간 기능은 겹칠 수 있다.

## 선정 기준과 확인 결과

- 누적 스타 순위 대신 GitHub Trending의 전체·언어별 월간 목록과 전체 주간·일간 목록을 확인했다. 선정한 레포 중 **64개**가 조회한 Trending 목록에서 관찰됐다.
- 나머지 **36개**는 분야 균형을 위한 보완 선정이다. 최근 코드 활동과 분야 적합성을 확인했지만 조회한 Trending 목록에서는 관찰되지 않았다.
- **58개**는 2023년 이후 생성된 레포다. 생성일은 프로젝트의 최초 출시일과 다를 수 있다.
- 100개 모두 아카이브 상태가 아니고, 이슈 기능이 켜져 있으며, 열린 이슈가 1개 이상이고 최근 30일 내 push가 있었다. 열린 이슈 수는 PR을 제외한 GitHub GraphQL `issues(states: OPEN).totalCount`다.
- 전통적 대형 플랫폼인 React, VS Code, Kubernetes 등의 원래 기본 목록을 교체했다. 분야 대표성을 위해 Svelte, DuckDB, Manim 등 오래된 프로젝트도 일부 유지했다.
- 이슈 기능이 꺼진 `jdx/mise`, 마지막 push가 2025-09-20인 `jordanbaird/Ice`는 제외했다.

이 목록은 수동 선정 스냅샷이다. 자동으로 최신 Trending으로 갱신하지 않는다.
Trending 링크의 내용과 API 수치는 이후 달라질 수 있다. 아래 날짜는 UTC 기준이며, 근거 링크는 선정 당시 조회한 목록이다.
열린 이슈가 있다는 사실이 초보자 기여 가능성을 보장하지는 않는다. 담당자·봇 제외와 모델 판정은 실제 수집 이후 적용한다.
레포 수를 균등하게 맞춰도 수집되는 이슈 수는 레포별로 다르다. 기존 리포트의 레포 집중도로 편중을 확인한다.

메타데이터는 인증된 `gh api graphql`로 조회했다.
원본 필드: `nameWithOwner`, `createdAt`, `pushedAt`, `isArchived`, `hasIssuesEnabled`, `issues(states: OPEN) { totalCount }`.
API 근거: [GitHub Repository 객체](https://docs.github.com/en/graphql/reference/objects#repository).

수집 경로 점검: 100개 모두 `gh api repos/{repo}/issues?state=open&per_page=1` 조회에 성공했다.
이는 API 접근 확인이며, 100개 레포의 전체 이슈 수집이나 모델 판정을 수행한 결과는 아니다.
