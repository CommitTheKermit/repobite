# 레포 카테고리 매핑

작성일: 2026-09-14

## 목적

정적 시안의 상단 레포 필터에 쓸 28개 레포의 단일 카테고리다. 이슈의 내용이나 GitHub 라벨을 분류하지 않는다. 같은 레포의 이슈는 모두 같은 레포 카테고리를 갖는다.

현재 원본은 `prototypes/layers.html`의 `article[data-category]`다. 분류 근거는 [수집 레포 시각 자산 조사](수집-레포-시각자산-조사.md)의 프로젝트 설명이다.

| --- | --- | ---: |
| AI | THU-MAIC/OpenMAIC, volcengine/OpenViking, ml-explore/mlx, mlc-ai/web-llm, cactus-compute/needle, semantica-agi/semantica, Tencent/AI-Infra-Guard, tt-a1i/archify | 8 |
| 프레임워크 | vbenjs/vue-vben-admin, withastro/astro, unovue/reka-ui, honojs/hono, better-auth/better-auth | 5 |

## 이번 범위 밖

- 칩 클릭에 따른 카드 표시와 개수 갱신
- 수집 결과와 레포 카테고리의 결합 또는 저장
- 새 레포 등록 시 카테고리 입력 화면과 검증
- 이슈별 버그, 문서, 기능 같은 별도 이슈 유형 태그
- AI를 이용한 자동 분류

## 이후 구현 원칙

1. 필터는 카드의 `data-category`를 기준으로 동작시키고, 카테고리별 건수는 그 데이터에서 계산한다.
2. 실제 수집을 연결할 때는 레포 등록 시 카테고리를 한 번 입력해 레포 메타데이터로 보관한다. 이슈 수집마다 AI 분류를 실행하지 않는다.
3. 이슈 유형 필터가 필요해질 때만 별도 태그 축을 추가한다. 이 경우에도 기존 난이도 판정 요청의 구조화된 출력에 함께 넣고, 결과를 `repo + issue number` 기준으로 재사용한다.
