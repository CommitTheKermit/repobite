## 이슈 판정과 다른 입력

번역 기회는 이슈가 없어도 원문, 번역 경로와 공식 기여 가이드를 비교해 만드는 별도 후보다.
현행 v2의 difficulty/readiness를 부여하지 않는다. 파일 경로의 누락과 실제 번역 필요성은 다르다.
같은 내용이 다른 저장소나 경로에 있거나 새 문서를 번역 대상에서 제외했을 수 있다.

## 표시할 후보의 계약

각 후보는 저장소, 원문 경로/SHA, 예상 번역 경로, 가이드 경로/SHA, revision과 조회 시각을 포함한다.
한국어 누락 후보는 대응 경로 없음으로 표시하고 조회 오류는 미확인으로 표시한다.
기존 번역이 있는 경우 원문과 번역의 수정 시각이 다르다는 이유만으로 낡았다고 단정하지 않는다.
원문 기준 revision 등 비교 근거가 없으면 갱신 필요 여부는 미확인이다.
출판 전 다른 번역 위치, 관련 열린 PR과 유지관리자의 번역 규칙을 확인해야 한다.

범위 선택은 한국어 누락 후보부터 시작할지, 기존 번역의 갱신 필요 신호까지 포함할지 사용자에게 질문했다.
저장소와 대상 문서 매핑이 정해지기 전 임의로 레포 전체 파일을 번역 대상으로 삼지 않는다.
