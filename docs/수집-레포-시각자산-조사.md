# 수집 레포 시각 자산 조사

조사일: 2026-09-14

대상은 `.radar-web/current/issues.jsonl`에 실제 이슈가 수집된 레포 28개다. GitHub GraphQL과 README API의 원본 응답을 기준으로 조사하고, 선택한 URL이 실제 이미지로 응답하는지 확인했다.

## 결론

- 10개는 저장소 관리자가 직접 지정한 소셜 미리보기를 바로 사용할 수 있다.
- 14개는 README에서 프로젝트를 설명하는 로고, 제품 화면, 데모 또는 배너를 고를 수 있다.
- 4개는 적절한 대표 이미지가 없어 소유자 아바타 기반 fallback이 필요하다.
- 따라서 현재 표본은 28개 모두 카드 자산을 구성할 수 있고, 그중 24개는 레포가 제공한 대표 자산을 사용할 수 있다.
- GitHub가 자동 생성한 기본 OG와 배지, 통계, 후원 이미지는 대표 자산에서 제외했다.

## 적용 규칙

1. `custom OG`가 있으면 카드 대표 이미지의 첫 후보로 사용한다.
2. `README` 자산은 배지, 통계, 후원 이미지를 제외하고 프로젝트를 설명하는 화면, 데모, 배너 또는 로고만 사용한다.
3. `fallback`은 아바타를 로고처럼 작게 두고 프로젝트 설명과 주 언어를 함께 표시한다.
4. 원격 URL은 수집 원본으로 보관하되 서비스 화면에서는 실패와 변경에 대비해 캐시 또는 프록시를 둔다.
5. 실제 서비스에 노출하기 전 각 저장소의 자산 라이선스와 사용 조건을 확인한다.

## 검증과 한계

- 선택한 28개 URL은 조사 시점에 HTTP 200과 이미지 Content-Type으로 응답했다.
- README 후보 추출은 Markdown 이미지와 HTML `img`를 대상으로 했다. 홈페이지 내부 이미지와 CSS 배경은 조사하지 않았다.
- 원본 저장소가 자산을 교체하거나 삭제하면 URL 또는 내용이 바뀔 수 있다.
