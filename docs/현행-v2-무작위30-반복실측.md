# 현행 v2 무작위 30건 반복 실측

확인일: 2026-10-21. `gemini-3.1-flash-lite`, `minimal`, `criteria_version=2`를 사용했다.
본문 완결성 등급과 이에 대응하는 readiness를 평가했다. 구현 난이도에 대한 실측이 아니다.

기본 `repos.txt`의 30개 저장소에서 최근 7일 갱신 이슈를 수집하고, 제외 규칙을 통과한
699건에서 고정 무작위 30건을 뽑아 독립적으로 두 번 새 판정했다. 각 반복의 원시 후보는
22/30건(73.3%), freshness 통과 후보는 18/30건(60.0%)이었다.
등급, readiness, 제외 여부와 원시 추천 여부는 성공 공통 30건에서 모두 일치했다.
사람 감사를 수행하지 않았으므로 정확도, 정밀도와 재현율은 측정하지 않았다.

## 수집과 표본

- 수집 시작: 2026-10-21 11:08:35 KST, 완료: 11:09:05 KST
- 갱신 시각 창: 2026-10-14 11:08:35.249844 KST부터 2026-10-21 11:08:35.249844 KST까지
- 창 기준은 GitHub `updated_at`이다. 생성일 기준 최근 7일이라는 의미가 아니다.
- 기존 수집과 같은 `state=open`, `since`, 페이지 순회 및 PR/담당자/봇 제외 규칙을 사용했다.
- 조회 1,952건 중 PR 1,172건, 담당자 있음 77건, 봇 작성 4건을 제외해 풀 699건을 확보했다.
- 제목이나 본문, 특정 정답 여부로 표본을 골라내지 않았다.
- `repo.lower()/number` 정렬 후 Python 3.14 `random.Random(20261021).sample`로 30건을 추출했다.
- 표본에는 12개 저장소가 포함됐다. 한 저장소의 최대 표본 수는 6건이다.
- README 대표 이미지 선정은 이 평가와 무관한 유료 호출을 추가하므로 수행하지 않았다.

기존 `radar.grade`를 호출했고 각 반복마다 새 출력과 서로 다른 빈 재사용 파일을 사용했다.

모델, 프롬프트, 기준, 온도, 출력 토큰 및 HTTP 재시도 정책을 변경하지 않았다.
